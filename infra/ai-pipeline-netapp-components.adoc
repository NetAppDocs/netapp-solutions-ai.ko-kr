[[4-1-netapp-xcp-core-value]]
== 4.1 NetApp XCP — 핵심 가치

XCP는 데이터 위치와 컴퓨팅 위치를 분리하는 모빌리티 계층입니다. 단일 구성 스위치 (`xcp++_++copy++_++destination`)를 통해 준비된 데이터와 모델 아티팩트가 NetApp ONTAP S3 또는 LustreFS 고성능 계층에 저장될지 여부가 결정되며,  `model++_++training`,  `fine++_++tuning`, 및  `inferencing`는 동일한 대상에서 자동으로 읽기 및 쓰기 작업을 수행합니다.
