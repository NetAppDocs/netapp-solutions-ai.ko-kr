= TR-4492: NetApp ONTAP 기반 MongoDB
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


Karthikeyan Nagalingam, NetApp

[role="lead"]
이 참조 아키텍처는 VMware vSphere를 사용하여 NetApp ONTAP에서 가상화된 샤딩 MongoDB 데이터베이스를 배포하고 보호하는 방법을 보여줍니다. MongoDB 팀에게 일관된 낮은 지연 시간 성능, 백업, 복구, 개발/테스트 및 QA를 위한 즉각적인 공간 효율적인 복사본, 그리고 클라우드의 ONTAP으로의 재해 복구를 제공합니다. 스케일아웃 NetApp AFF 어레이는 MongoDB 가상 머신(VM)과 데이터베이스를 호스팅합니다. NetApp SnapCenter는 MongoDB 환경의 NetApp 스냅샷 복사본을 관리하고, SnapMirror는 이를 클라우드로 복제합니다. 이 보고서에서는 MongoDB Atlas에서 NetApp Digital Advisor를 제공하는 경우와 Ops Manager를 사용한 엔터프라이즈 MongoDB 백업 및 복구라는 두 가지 고객 사용 사례도 설명합니다.

MongoDB는 널리 사용되는 오픈 소스 확장형 NoSQL 데이터베이스입니다. 읽기 및 쓰기 지연 시간이 짧고, 고가용성 및 고급 데이터 관리가 필요한 최신 데이터 레이크 애플리케이션을 구동합니다. MongoDB의 주요 사용 사례로는 실시간 분석, 제품 카탈로그, 콘텐츠 관리 및 모바일 애플리케이션 등이 있습니다.

NetApp 솔루션은 미션 크리티컬 MongoDB 애플리케이션 배포에 다음과 같은 주요 이점을 제공합니다:

* 직접 연결 스토리지에 비해 일관되게 낮은 지연 시간과 예측 가능한 고성능을 통해 MongoDB 기반의 가장 까다로운 분석 애플리케이션에 탁월한 응답 시간을 제공합니다.
* 인라인 중복 제거 및 압축을 통해 인라인 효율성을 높여 MongoDB에 필요한 플래시 스토리지를 최소화합니다.
* 새로운 스토리지를 구매할 필요 없이 개발/테스트 또는 QA 환경을 신속하게 구축할 수 있는 즉각적이고 공간 효율적이며 비용 효율적인 데이터베이스 복제 솔루션입니다.
* 공간 효율적인 NetApp 스냅샷 기술을 기반으로 한 백업 및 복구와 클라우드로의 원격 복제.
* MongoDB를 사용하여 스토리지를 모듈식으로 확장할 수 있는 스케일업 및 스케일아웃 AFF 어레이를 통해 뛰어난 확장성을 제공합니다.
* 특히 드라이브 장애 발생 시에도 최대 가동 시간과 일관된 성능을 제공하는 고가용성을 통한 중단 없는 운영이 가능합니다.
* 이기종 환경에 MongoDB를 배포하여 유연성을 제공하고 추가적인 비용 절감을 실현합니다.
* NetApp SnapCenter를 사용한 백업, 복원 및 클로닝의 단일 인터페이스 관리.
